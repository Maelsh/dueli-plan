### موجّهات قصيرة عامة للقائد

**عند وصول تقرير LOCAL:**
```
هذا تقرير LOCAL للوحدة [x.y]. تحقق من اكتماله شكلياً، ثم أصدر موجّه REMOTE بالقالب B.
```
**عند وصول حكم REMOTE:**
```
هذا حكم REMOTE للوحدة [x.y]. إن كان APPROVE: أصدر تعليمات الدمج والوحدة التالية.
إن كان REJECT: أصدر موجّه إصلاح LOCAL على نفس الفرع يعالج البنود الحاجبة فقط.
```
**عند وصول نتيجة 👁️ أو 🧑:**
```
هذه نتيجة بطاقة [x.y]. حدّث الحالة، وحوّل كل S0/S1 إلى وحدات إصلاح، وأخبرني هل تحقق معيار خروج المرحلة.
```
