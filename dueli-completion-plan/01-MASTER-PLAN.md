## 1. النطاق المعتمد

- خطة16 وBeta Core وFoundation والخوادم وTURN والبث والمال والإعلانات التاريخية وR1 مغلقة وفق قرار المالك؛ لا إعادة بوابات أو إثباتات عامة.
- الوحدات البرمجية R2/R3 السابقة مدموجة وفق سجل14؛ قبول الوسائط والإجراءات البشرية مستقل عن CODE DONE / DEPLOYED.
- المتبقي: عيوب استخدام محددة موثقة، تكامل signaling واستقبال المقاطع والتسجيل والتنزيل وصفحة المنافسة الموحدة، الرسائل والحفظ وHome والاستهلاك وUX واللغة والإدارة، توسعة الدليل، الإجراءات البشرية اللازمة والقبول وإطلاق الويب.
- R5 للمنصات اللاحقة بعد الويب؛ لا يحجب البيتا. KEEP NOW للتخليقي ثابتة؛ C3 تصميم مستقبلي فقط.
- يمكن تعديل العقد/الخلفية الضرورية لعيب مثبت؛ لا إخفاء خلل منطقي في الواجهة ولا إعادة بناء خدمة مغلقة.

## 2. الثوابت

08 هو مرجع المالك و11 مرجع h7-v1 المعتمدة؛ لا إعادة تصميم أو سؤال الأوزان. كل قسم وفرع يخضع لترتيبها داخل مجموعة النتائج المؤهلة، مع ثبات الجلسة والاستمرار حتى النفاد.

التقييم بعد300 ثانية مشاهدة حية تراكمية لنفس المنافسة،1–5 لكل طرف، تعديل حتى النهاية، حصيلة حية مؤقتة ثم إغلاق خادمي. لا تقييم جديد في التسجيل. مؤشر Profile وفق الصيغة المحسومة في08، لا متوسط بعدد المصوتين.

20%/80%، السنتات، الفائز بالمتوسطات والتوزيع بالمجموع، ELO، الذرية وidempotency والتاريخ محفوظة. لا إعادة احتساب تاريخي. فصل نهاية المنافسة وcutoff عن اكتمال آخر رفع للتسجيل.

P2P للطرفين فقط؛ المضيف وحده يسجل ويرفع الصورة المركبة والصوتين؛ الجمهور يستقبل المقاطع. انقطاع المضيف لا ينهي المنافسة، والعودة تضيف دون استبدال، وقائمة الخادم ونهاية موثقة هما مرجع التسجيل. صفحات الاختبار تبقى؛13 يحدد دمج الأدوار داخل المنافسة.

OOP/MVC وSQL فيModels فقط، ar/en وRTL/LTR وCSP وdark/mobile وkeyboard/aria في الأسطح المتأثرة. لا خدمة مدفوعة أو نقلDB أو كتابة إنتاجية أو منح دور أو تحويل مال أو حذف بيانات بلا التفويض المحدد.
